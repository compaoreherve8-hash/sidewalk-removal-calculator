SIDEWALK REMOVAL CALCULATOR V5

Changes: Left only / Right only / Both; no mandatory entries on an unselected side; editable F/S and landing proposed slopes; absolute slope differences; default example: Ramp 11/7 x 9 ft, Landing 2.6/1 x 6 ft, Left 9.5/7 => 18.24 ft.

Android deployment: unzip and upload all extracted files to the ROOT of your existing GitHub repository, replacing the files with matching names. Do NOT upload just the ZIP. Keep the existing GitHub Pages settings: branch main, /(root). Open the published HTTPS address in Chrome and reload online to fetch the new version. The service worker will refresh cached files on network access.

This is an experimental preliminary design aid. It cannot certify ADA/MnDOT compliance. Grade directions, elevations, transitions, and route classifications require engineering verification.
